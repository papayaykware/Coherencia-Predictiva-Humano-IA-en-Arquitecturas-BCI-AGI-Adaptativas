# CONTRIBUTING

## Philosophy

This repository is experimental and interdisciplinary.

Contributions are encouraged in:

- signal processing,
- neuroscience,
- machine learning,
- continual learning,
- symbolic systems,
- geomagnetic analysis,
- adaptive architectures.

---

# Contribution Rules

## Code

- Keep modular structure.
- Use descriptive naming.
- Add comments for experimental logic.
- Maintain reproducibility.

---

## Research Integrity

Clearly distinguish:

- validated science,
- theoretical speculation,
- exploratory hypotheses.

---

# Pull Requests

Please include:

- objective,
- methodology,
- expected outcome,
- reproducibility notes.

---

# Experimental Orientation

The repository explores unconventional architectures and speculative models.

All contributors should preserve:

- technical rigor,
- transparency,
- reproducibility,
- explicit uncertainty labeling.
